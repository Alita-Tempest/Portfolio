The idea

The site is modelled on a printed circuit board, because that's what I do. The hero is a routed board with traces at 45° and 90°, carrying signal pulses along the copper. Section headers are silkscreen legends, project cards carry component designators, and the theme switch is a layer selector: silkscreen, copper, or bare FR-4 substrate.

The previous version was an adapted Bootstrap template. This one is written from scratch.

How it's built

No framework, no bundler, no package manager — one stylesheet, one script and static HTML, so deploying is a git push and nothing can rot in a dependency tree.

The old version loaded nine vendor libraries totalling about 22 MB, most of them unused on every page. All of it is gone. The lightbox is a native <dialog>, the filter is nine lines of JavaScript, and the typing effect is a setTimeout.

Performance and motion

Every image is pre-generated to AVIF and WebP at four widths and served through <picture>. The original library was 114 MB of unoptimised JPEG and PNG; the derivatives are a fraction of that, and any single page pulls only a handful. Fonts are self-hosted variable subsets — three families, 100 KB.

Scroll reveals use CSS scroll timelines where the browser supports them, with an IntersectionObserver fallback. Navigating to a case study uses cross-document View Transitions so the card morphs into the page hero instead of flashing white.

All of it is gated on prefers-reduced-motion in both CSS and JavaScript. If you have reduced motion enabled, nothing here moves.
